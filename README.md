# DriftMod Standalone (v0.9.8 Beta)

> [!NOTE]  
> **Status: Prototype / v0.9 Proof of Concept (PoC)**  
> This project represents an initial exploration and proof-of-concept for standalone handling manipulation and drift menus in FiveM (Lua).  
> It is preserved as a public technical reference and baseline experiment. A completely refactored, high-performance next-generation drift engine is under active private development.

---

## Overview

A standalone drift menu and vehicle dynamics modifier developed for FiveM servers:
- **Standalone architecture:** Independent of server frameworks (ESX/QBCore).
- **Vehicle handling manipulation:** Dynamic drift mode toggles and physics tweaking via native FiveM APIs.
- **In-game menu:** Real-time controls for vehicle handling characteristics.

## Tech Stack
- **Language:** Lua
- **Platform:** FiveM CitizenFX FXServer
